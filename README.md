# CS320_SOFTWARE_TESTING-AUTOMATION
In this course we learned how to test software using JUnit.

REFLECTION

->How can I ensure that my code, program, or software is functional and secure?
I can make sure that software is functional and secure by testing often and utilizing software like JUnit when necessary.

->How do I interpret user needs and incorporate them into a program?
When understanding the needs of a user, I will make sure to understand what they want in a program. Write down what they need then gather information such as budget and other constraints. I will then discuss feasibility of their request before moving on to design. This will help ensure I am meeting the users' needs while building a functional product.

->How do I approach designing software?
I like work slow, by breaking down the project into smaller pieces, working on them one at a time. I start with the basics, test, the build some more. This tactic has helped me throughout my journey including in this class.
